# HATENA. Portfolio

黒 × シアンを基調にした、HTML / CSS / JavaScriptだけで動くレスポンシブなポートフォリオサイトです。外部ライブラリは不要です。

## ファイル構成

```text
neon-portfolio/
├── index.html
├── style.css
├── script.js
├── README.md
└── assets/
    ├── images/
    ├── thumbnails/
    └── icons/
```

## GitHub Pagesへの公開

1. GitHubで `HatenacatYT.github.io` リポジトリを開きます。
2. `index.html`、`style.css`、`script.js`、`README.md` と `assets` フォルダをリポジトリのルートにアップロードします。
3. 既存のテスト用 `index.html` を置き換える場合は、内容を保存する前に必要な部分をコピーしておいてください。
4. **Settings → Pages** で `Deploy from a branch`、`main`、`/(root)` が選ばれていることを確認します。
5. 数分後に https://hatenacatyt.github.io/ を再読み込みします。

## 公開前に編集する場所

- `index.html` の `HATENA`、自己紹介、プロジェクト説明を自分に合わせて変更します。
- GitHubリンクは現在 `https://github.com/HatenacatYT` に設定しています。
- YouTubeリンクはサンプルとしてYouTubeトップページにしています。自分のチャンネルURLに置き換えてください。
- プロジェクトカードはサンプル紹介です。実際の公開状況に合わせ、説明・リンク・画像を変更してください。
- Google Fontsはネット接続がある場合に読み込まれます。読み込めなくてもシステムフォントで表示されます。

## ローカル確認

`index.html` をブラウザで開くだけで確認できます。サーバーやビルド手順は不要です。
